# Dental Clinic Management System

A web-based project developed by a team of three students as part of the Introduction to Web Computing course.

## Technologies Used
- HTML
- CSS
- Bootstrap
- JavaScript
- PHP
- MySQL

## Project Description
This system helps manage patient records and appointment scheduling for a dental clinic. It provides a simple and responsive interface and stores data securely in a MySQL database.

## Features
- Patient management
- Appointment scheduling
- Responsive design
- Database integration

## Team Project
This project was completed collaboratively by three students.
